# NANWES Social Hub — GitHub Pages

Sitio informativo público para la verificación de URL de TikTok, independiente del panel Apps Script.

## Publicar gratuitamente
1. En GitHub abre https://github.com/Hernanqm/patsman/settings/pages
2. En **Build and deployment** selecciona **Deploy from a branch**.
3. Selecciona la rama **nanwes-pages** y carpeta **/(root)**. Guarda.
4. Comprueba https://hernanqm.github.io/patsman/ y https://hernanqm.github.io/patsman/privacy.html y https://hernanqm.github.io/patsman/terms.html.
5. En TikTok, selecciona **URL prefix**, introduce https://hernanqm.github.io/patsman/ (con barra final) y descarga su archivo de firma exacto.
6. Sube el archivo sin renombrar a la raíz de esta rama. Comprueba la dirección pública y vuelve a TikTok para confirmar.

No subas nunca contraseñas, tokens, claves privadas ni secretos al repositorio. La aprobación de TikTok no está garantizada. Revisa el contenido legal antes de solicitar revisión de la aplicación.
